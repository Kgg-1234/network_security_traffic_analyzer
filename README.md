# Network Security Traffic Analyzer

A Python-based network security project for capturing and analyzing network packets.

## Project Goals

* Capture and inspect network traffic
* Identify common network protocols
* Extract packet information
* Analyze basic traffic patterns
* Detect potentially suspicious network activity

## Technologies

* Python
* Scapy
* Wireshark
* Git and GitHub

## Project Status

🚧 Under Development
